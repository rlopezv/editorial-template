# Workflow

The editorial workflow is phase-based and session-driven.

## Phases

0. Inception
1. Corpus Intake
2. Corpus Governance
3. Domain Grounding
4. Structural Analysis
5. Index Synthesis
6. Chapter Production
7. Editorial QA
8. Publication

Each phase has:

- documentation in `phases/`
- prompts in `prompts/phases/`
- scripts in `scripts/phases/`
