# Repository Structure

- `corpus/` raw and normalized knowledge inputs
- `manuscript/` final markdown content
- `index/` book or document structure
- `references/` canonical grounding material
- `editorial/` editorial rules, terminology, policies
- `editorial-graph/` coherence engine
- `sessions/` session templates, prompts, checkpoints
- `prompts/` phase prompts and graph prompts
- `scripts/` automation and validations
- `templates/` reusable content and metadata templates
